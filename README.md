# Atlas Sweeper

A retro CRT terminal-styled Minesweeper clone.

## Features

- Classic Minesweeper gameplay
- Three difficulty levels: Beginner (9x9, 10 mines), Intermediate (16x16, 40 mines), Expert (30x16, 99 mines)
- Full keyboard navigation support
- CRT terminal aesthetic: scanlines, curvature, glow, vignette, phosphor fade
- Smooth animations: screen flicker on start, cell reveal, flag placement, timer ticks, win/loss overlay
- Fully offline; no external dependencies

## How to Play

- **Left Click** or **Space/Enter**: Reveal cell
- **Right Click** or **F**: Toggle flag
- **Arrow Keys**: Move selection
- **R**: Restart game
- **Esc**: Close overlays

## Run Locally

Open `index.html` in any modern browser.
